关于 TCCI

面向科研驱动型机构的技术合作伙伴。

TCCI 是一家专注于 IT 项目管理办公室（PMO）解决方案的 IT 初创公司，为研究办公室、高校 ORIC 中心及产业创新中心提供企业级数字系统。作为一家 IT 公司，我们的专长涵盖 Web 开发、IP 软件工程、云基础设施和 IT 咨询。

我们的使命是通过安全、自动化的工具，降低发明成果从高校实验室走向实际商业运营的壁垒。

  • Web 开发
  • 软件工程
  • 云基础设施
  • IT 咨询
